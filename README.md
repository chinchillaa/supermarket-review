# どこスーパー

東京都23区外のスーパーで「何が、どの店舗に、いつ売っていたか」を、ログインユーザーの口コミで共有するWebサービスです。

## 初期方針

- 対象地域：東京都23区外。まずは多摩地域を先行し、島しょ部は後から追加
- 対象店舗：多摩地域の主要スーパーを中心に段階的に登録
- 対象商品：食品・飲料・日用品
- 利用者：ログインユーザーのみ
- 形態：Web版のみ
- 料金：初期公開は無料サービスのみで運用
- 商品識別：JANを基本キーにし、ユーザーによる商品追加を可能にする

## MVP

- Googleまたはメールによるログイン
- 店舗・商品検索
- 店舗ページ、商品ページ
- 店舗、商品、価格、在庫状態、確認日時、コメント、写真の投稿
- JAN入力による商品追加申請
- 「役に立った」評価
- 投稿の編集・削除、違反報告
- 管理者による店舗・商品・投稿の管理

## 開発方針

商品・店舗データは、出典、利用条件、最終確認日を記録します。公開されている情報であっても、再利用条件が明確でないデータを無断で一括転載しません。
