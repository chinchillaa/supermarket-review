# 開発計画

## 1. 対象地域

「東京都23区外」を対象とし、初期公開は多摩地域を優先します。店舗情報と口コミが不足しやすいため、島しょ部は初期MVPの対象外とし、運用基盤が安定した後に追加します。

## 2. 無料運用前提の構成案

- フロントエンド：Next.js
- データベース・認証・画像保存：Supabase Free
- ホスティング：Vercel HobbyまたはCloudflare Pages
- ソース管理：GitHub
- 独自ドメイン：初期は使用せず、無料のサービスURLを利用

無料枠は変更される可能性があるため、公開前に各サービスの最新の利用条件を確認します。画像には容量制限を設け、利用量を監視します。

## 3. 初期データ

### 店舗

店舗名、住所、緯度経度、営業時間、公式URL、出典、最終確認日を管理します。最初から全店舗を網羅せず、多摩地域の主要チェーンを中心に段階的に追加します。

### 商品・JAN

商品はJANを基本キーとします。ただし、内容量、味、セット構成、リニューアル商品が異なる場合は別商品として扱います。

初期データには利用条件を確認できるデータのみを使い、各レコードに以下を保存します。

- 情報源
- ライセンスまたは利用条件
- 取得日
- 最終確認日
- データの信頼度

ユーザーはJAN、商品名、メーカー、内容量、写真を使って商品追加を申請できます。

## 4. データモデル

- `users`
- `stores`
- `products`
- `product_aliases`
- `reviews`
- `review_images`
- `helpful_votes`
- `reports`
- `data_sources`
- `product_suggestions`
- `store_suggestions`

口コミには、投稿日時とは別に「実際に商品を確認した日時」を保存します。古い情報を利用者が判断できるようにするためです。

## 5. 開発順序

1. プロジェクト基盤、環境変数、Lint、テスト設定
2. Supabaseの認証・DB・Row Level Security
3. 店舗・商品・口コミの登録と検索API
4. ログイン、検索、店舗ページ、商品ページ
5. 口コミ投稿、画像、評価、通報
6. 管理画面と初期データ投入
7. 多摩地域の限定公開

## 6. 公開条件

- ログインできる
- 店舗と商品を検索できる
- 口コミを投稿・編集・削除できる
- JANで既存商品を重複登録しない
- 通報された投稿を管理者が確認できる
- 利用規約・プライバシーポリシーを表示できる
- 無料枠のデータベース・画像容量を超えない制限がある
